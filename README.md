🌸 Rovana Flowers Website - واجهة متجر زهور تفاعلية

واجهة موقع إلكتروني متكاملة ومستجيبة لمحل زهور باسم Rovana Flowers، مصممة لعرض المنتجات بطريقة عصرية ودافئة مع التركيز على تجربة المستخدم (UX) وجاذبية الواجهة (UI).

🚀 أجزاء والمميزات التقنية للموقع (Features)

• الصفحة الرئيسية (Hero Section): واجهة ترحيبية جذابة مع شعار المتجر.
• قسم أنواع الزهور (Kinds): بطاقات عرض المنتجات تحتوي على تفاصيل كل زهرة مع أزرار الإضافة إلى السلة.
• معرض الصور (Gallery Slider): عارض صور تفاعلي لعرض أحدث تنسيقات الباقات.
• صفحة الحساب (Login/Register): نموذج منسق لتسجيل دخول المستخدمين.
• صفحة من نحن والتواصل (About & Contact): عرض رؤية المتجر وأرقام التواصل وروابط المنصات الاجتماعية.
• التنسيق البصري: استخدام تأثيرات CSS3 حديثة وألوان متناسقة تناسب الهوية البصرية للمتجر.

🛠️ التقنيات المستخدمة (Tech Stack)

• HTML5 (Semantic Structure)
• CSS3 (Flexbox, Transitions, Custom Styling)
• VS Code
